# Rush Track — Godot Android

Original 2D hill-racing game built in Godot for Android phones and tablets.

## Target
- Android only
- Landscape orientation
- Touch-first controls
- Godot 2D / mobile-compatible renderer
- Offline-first runtime

## Structure

```text
godot/
  project.godot
  scenes/
  scripts/
  assets/
    lobby/
    vehicles/
    ui/
  docs/
```

All current art in this branch is authored for Rush Track. See `docs/ASSET_IP_POLICY.md` before adding new media or dependencies.
